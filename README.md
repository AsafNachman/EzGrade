# EzGrade 🎓

AI-powered study & exam generator: turns any course syllabus into a customized multiple-choice practice exam, grades your answers with detailed explanations, and shows the topics you need to work on.

**Team:** Asaf Nachman, Roi Hatamov, Ilai Sformes, Eliran Keinan, Yuval Mitrani, Salah Jaber

## How it works

1. **Upload a syllabus** (PDF, .txt, .md, or pasted text) and EzGrade extracts the course topics and subtopics.
2. **Configure an exam**: choose topics, a difficulty (easy / medium / hard) and the number of questions.
3. **Take the exam**: an interactive multiple-choice exam generated by Gemini.
4. **Get results**: a total score, a per-topic breakdown, your weak topics (below 70%), and an explanation for every question.

## Getting started

Requires Python 3.10 or newer.

```bash
git clone https://github.com/AsafNachman/EzGrade.git
cd EzGrade
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### Gemini API key (optional)

EzGrade uses Google Gemini to read syllabi and write questions. Get a free key at [Google AI Studio](https://aistudio.google.com/apikey) and set it before running:

```bash
export GEMINI_API_KEY="your-key"        # Windows (PowerShell): $env:GEMINI_API_KEY="your-key"
```

Without a key the app still runs in **offline mode**: topics are extracted from headings such as `Week 1: ...`, and sample questions are used instead of AI-generated ones.

### Run the app

```bash
streamlit run src/app.py
```

The app opens in your browser at http://localhost:8501.

### Run the tests

```bash
pytest
```

The tests never call the real Gemini API, so no key is needed.

## Project structure

```
src/
  app.py         Streamlit user interface
  parser.py      Syllabus -> list of topics
  generator.py   Topics -> multiple-choice exam
  grader.py      Answers -> score, weak topics and feedback
  validator.py   Input sanitization and exam quality checks
  llm_client.py  Fail-safe Gemini API wrapper
  models.py      Shared Pydantic data models
  storage.py     Saving exams/results and Markdown export
tests/           pytest unit tests
docs/            Project proposal
```
